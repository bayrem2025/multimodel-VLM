# Interpretable Multimodal Sentiment Analysis of Environmental Perceptions with Vision-Language Models

Text, image, and audio sentiment analysis of social-media content about energy, pollution, and carbon footprint, with explanations to support decision makers.

This project is developed alongside an industrial PhD (MOBIDOC) hosted by Hydatis.

## Technologies

- Python
- PyTorch
- Transformers
- PEFT / LoRA
- Qwen2-VL / LLaVA
- SHAP
- Label Studio
- Whisper
